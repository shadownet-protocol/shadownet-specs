# RFCs

`0001-shadownet.md` is the current Shadownet wire spec. `0002-shadownet-mcp.md` is the companion MCP control surface spec. `0003-shadownet-onboarding.md` is the companion onboarding URI spec.

Future numbered RFCs in this directory are amendment proposals against the consolidated specs. When an amendment is accepted, the spec doc is updated and the amendment RFC is archived. This keeps one canonical source of truth for "what does the wire say today" and a per-proposal trail for history.

Copy `0000-template.md` to the next free number and open a PR.
